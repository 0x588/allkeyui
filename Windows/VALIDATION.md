之前的六个 C ABI 入口、反复分配释放与独立进程验证另见 [PoC 记录](../WindowsPoC/VALIDATION.md)。

核心验收覆盖七币派生、WIF、BIP84、缺词搜索、已知公开地址匹配、自定义路径、目录边界、拼写提示、Electrum、UTF-8、排队取消、配置原子保存和损坏保护。
余额验收覆盖九类响应、超大整数与微小非零金额、缺失余额处理、请求合并、缓存、强制刷新、主备切换、自定义 EVM 投影和链 ID 拒绝。
这些余额测试使用本地 HTTP 测试桩，没有使用用户 API Key 或真实钱包。

UI 冒烟通过实际按钮及页面方法检查私钥生成和导航、错误保留原结果、BIP39 地址分页和缺词搜索、多组目录独立分页、Electrum、计算器 UTF-8/批量、160 题 Puzzle 范围、六个页面、主题保存及剪贴板所有权。
0.1.1 新增 37 项检查，对照 macOS 补齐助记词模块的模式、自动刷新、参数应用、输入补全、目录分组与生命周期。
0.1.2 再新增 28 项实际控件几何检查，覆盖三种窗口宽度、表单/按钮行、网络编辑器和深色主题。
0.1.3 新增 21 项结果内容检查，覆盖行内字段、复制、长密钥换行、余额状态、单词网格断点、Puzzle 列和模式返回。
0.1.4 新增 5 项 Puzzle 自动余额刷新检查，覆盖并发、离页与迟到结果、重新进入、公开地址与缓存、手动刷新。
这套检查是基础回归，不等于穷举所有组合；46 个计算器操作沿用现有 Go 实现，UI 抽检 SHA256 和编码/批量。

## 发布包

以下哈希对应本地验收包；GitHub 发布附件增加了双语说明和第三方许可文本，公开下载包的最终哈希请以 Release 附带的 `SHA256SUMS.txt` 为准，应用二进制保持一致。
